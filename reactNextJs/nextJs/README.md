# Next.js Portfolio (Example)

This is a minimal Next.js portfolio scaffold demonstrating:

- Page-based routing (pages/)
- Styling (global CSS + CSS modules)
- Image handling (public/ images + next/image)
- Deployable to Vercel or similar platforms

Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000

Deploy

This app can be deployed to Vercel with the default settings (no extra config required).
